# 🍋 Little Lemon — iOS Capstone Project

## About the Project

Little Lemon is an iOS restaurant application developed using Swift and SwiftUI as part of the Meta iOS Developer Professional Certificate on Coursera.

The application allows users to create a profile, explore a Mediterranean restaurant menu, search for dishes, filter food categories, and manage their personal information.

## Features

- **Welcome Screen:** Introduction to the Little Lemon restaurant.
- **User Onboarding:** Register using first name, last name, and email address.
- **Home Screen:** Restaurant information and food menu.
- **Menu Search:** Search for dishes by name.
- **Category Filtering:** Filter dishes by Starters, Mains, Desserts, and Drinks.
- **Restaurant Menu:** Display dish names, descriptions, prices, and images.
- **API Integration:** Fetch restaurant menu data from a remote JSON endpoint.
- **Core Data:** Store and retrieve menu information locally.
- **User Profile:** Edit personal information and email notification preferences.
- **Logout:** Return to the welcome screen and allow a new onboarding session.

## How to Run

1. Clone or download this GitHub repository.
2. Open `Littlelemon.xcodeproj` in Xcode.
3. Select an available iPhone Simulator.
4. Build and run the application.
5. Complete onboarding to explore the restaurant menu.
